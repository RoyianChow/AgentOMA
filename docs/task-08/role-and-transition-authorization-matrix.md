## 5. Cross-gate prohibitions and state separation

- **Patient/agent versus professional:** submitting evidence, supplying clarification, consenting or choosing a pharmacy cannot set a professional gate. A valid recipient grant cannot authenticate a professional; a professional session is not a patient-session bypass.
- **Technical versus professional:** inventory confirmation cannot authorize preparation if another guard is incomplete; preparation cannot pass a professional check; technical completion cannot replace pharmacist-only clinical judgment. Technician, intern/student, assistant, administrator, support and courier mappings are never silently widened.
- **Negative decisions still require authority:** professional REJECTED/FAIL/REVOKED states require supported attributed decisions. Engineering may deny advancement for missing/stale evidence without pretending a professional made a negative decision. Preserve unknown/pending truth and safe generic errors.
- **Release versus readiness:** READY requires current `RELEASE_AUTHORIZED`, valid mode, package in pharmacy custody, valid recipient/approved delivery plan, approved release validity and no cancellation/revocation/exception/reconciliation blocker. Remove or mark readiness stale when a guard changes. No new ready-state command or permissive validity duration is defined here.
- **Per-item independence:** a source decision applies only to its verified item/version. An approved multi-item/split plan is required where applicable; one released item cannot release a request/package containing other unready items. No automatic partial-fill or quantity decision.
- **Custody versus receipt:** courier acceptance/transport is not patient receipt; failed, delayed, disputed or unknown delivery cannot be marked received. Pharmacy acceptance of valid matched recipient proof is separate. Revocation blocks future unsafe handoff but cannot rewrite an already observed physical transfer.
- **Return versus disposition:** verified delayed return is still pharmacy custody; preserve delay/exception evidence. RETURNED never means saleable, re-dispensable or refunded. G15 is a separate professional decision; AgentRx does not execute restock/disposal or financial consequences.
- **Money versus professional truth:** payer/adjudication/payment/claim sources stay independent. No gate, request, pickup, delivery, return, cancellation or reconciliation may create/code/submit/reverse a claim or infer dispensing/service completion. Current advisory claim behavior is not a production adjudication/submission API.
- **External event versus decision:** a signed webhook, imported record or service-account message must not directly set these gates. Unknown mapping/source/version or uncertain side effects enters reconciliation before any safe retry; reconciliation cannot invent professional, physical or financial truth.
- **Privacy and communication:** public intake stays zero-PHI; approved Task 05 access is missing. Task 07 remains the only proposed generic-notice/secure-message authority, not an implemented channel or a shortcut for counselling. No PHI, credentials or raw professional evidence in URLs, browser persistence, logs, analytics, technical audit/outbox or unsafe errors.
