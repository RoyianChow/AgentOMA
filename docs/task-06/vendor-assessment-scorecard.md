# Task 06 — Vendor Assessment Scorecard

**This is a template populated with only publicly verifiable facts, not a vendor ranking.**
Per the task's own decision rules, marketing pages are not evidence, and this task does not
authorize vendor contact. Every field below that would require vendor-provided evidence
(contract, PIA/TRA, subprocessor list, technical documentation) is marked `UNAVAILABLE —
requires direct vendor engagement`, not filled from a marketing page.

**Do not treat any row below as a recommendation.** It exists so that a future, authorized
procurement step has a ready-made structure to fill in, and so this task's own instruction —
*"identify unavailable vendor evidence"* — has a concrete, auditable answer.

## What this table actually proves

Only two things are verified: (1) Ontario Health lists each of these as *reviewed for privacy
and security documentation* for the tagged modality, as of the access date, and (2) that review
is explicitly not an "assessment" or approval, per Ontario Health's own wording. Every
integration-relevant, privacy-relevant, and commercial question needed to actually choose
between them is unavailable without direct vendor engagement — which this task does not
authorize.
